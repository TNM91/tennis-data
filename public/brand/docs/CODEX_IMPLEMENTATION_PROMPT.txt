TENACEIQ BRAND IMPLEMENTATION

Approved originals are in public/brand/approved/. Preserve them byte-for-byte.
Use the full light wordmark on dark UI and the full dark wordmark on light UI.
Use TiQ_White_Transparent_Refined.png for compact marks on dark UI and
TiQ_Navy_Transparent_Corrected.png for compact marks on light UI. Keep the
TiQ app icon for square icon tiles and device icons.

Preserve aspect ratios, supplied transparency, tennis-ball seams, colors,
letter shapes, and spacing. Never redraw, recolor, crop, skew, stretch, filter,
round, or regenerate supplied artwork. Use object-fit: contain and clear space.

The dark header uses the full wordmark: 178px on phones and 200px on wider UI.
The court net uses the transparent white TiQ mark centered on the existing net.
Court geometry and interaction coordinates must remain unchanged.
The social card mixes the full wordmark and transparent TiQ mark.
Tour posters and video lockups use approved artwork; retain narration,
captions, timing, and CTA destinations.

Canonical share card: /brand/social/og-approved-20261024.png.
Use versioned URLs for Next Image aliases and media when artwork changes.
Allow only the exact version query strings needed in images.localPatterns.

Refresh court/social/poster compositions with node scripts/refresh-approved-brand-media.mjs.

Historical SVGs are retained but are not the source for the new raster artwork.

Verify dark/light placement, phone/tablet/desktop headers, transparent edges,
original icon bytes, correct favicon/Apple/PWA references, video playback,
captions, court geometry, and share metadata. Never deploy to production
