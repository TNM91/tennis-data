# Apple app feature migration

The bundled iPhone client is the main product. The website continues to host shared APIs and account/support routes while features move into native screens. Android is deferred. Existing signed-in accounts and team data are reused.

| Area | Available in the iPhone beta | Remaining substantial work |
| --- | --- | --- |
| My Lab | Linked profile, ratings, recent results, player connection, team alert registration | Full personal analysis, profile editing, richer season insight |
| Explore | Player/team/league directories, details, rankings, follows, comparisons | Complete public intelligence tools and deeper cross-navigation |
| Team conversation | Live text, replies, reactions, reports/blocks, private photos, inline previews, per-team mute | Animated GIF/video sharing, older-history pagination, richer conversation layout |
| Coordination batch | Own-post editing/removal, recent-message search, availability replies, versioned lineup review, final-lineup seen, assigned-player arrival | Physical-device acceptance of these new actions |
| Captain | Shared court plans, match-day player actions, native upcoming matches, roster search, fixture-specific availability overview, saved-lineup review and private lineup creation/editing with safe saves | Confirmed lineup publication, availability planning, scouting, weekly brief, captain management |
| League coordination | Read-only league discovery and rankings | Creation, scheduling, results administration and organizer workflows |
| Account/store readiness | Secure sessions, password recovery, privacy/support links, APNs, signed internal beta | Account deletion flow, verified auth links, store purchases/restore and entitlement reconciliation, final disclosures and reviewer flows |

Batch related features behind one reviewable candidate and one beta build. Keep accepted-team scope, role/tier boundaries, moderation and retry safety aligned with shared server behavior. No public App Store submission is authorized by routine internal beta approval.
